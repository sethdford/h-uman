# Architecture-support finding (static, zero weight-loading -- see
# scripts/mlx_tune_train.py::resolve_architecture_support and the dry-run
# output recorded in docs/research/v6-orpo-execution-record-20260727.md):
#
# mlx-tune has NO explicit named "supported architectures" registry/allowlist
# for text LLMs (grepped mlx_tune/*.py for SUPPORTED/ARCH_REGISTRY/registry/
# ARCHITECTURES -- none exists for LLMs; only OCR/embeddings/audio submodules
# have their own small per-feature allowlists, unrelated to GLM). Text-model
# architecture support is inherited entirely from mlx_lm: mlx-tune loads via
# `mlx_lm.load()` / `mlx_lm.utils._get_classes(config)`, which dispatches on
# config.json's "model_type" to `mlx_lm.models.<model_type>` -- and applies
# LoRA (incl. per-expert MoE LoRA) via dynamic introspection
# (mlx_tune.model._resolve_target_modules scans live module types for
# nn.Linear/nn.QuantizedLinear/SwitchLinear/QuantizedSwitchLinear), not a
# name-keyed table.
#
# GLM-4.5-Air-4bit's config.json (cached locally,
# ~/.cache/huggingface/hub/models--mlx-community--GLM-4.5-Air-4bit) reports
# model_type=glm4_moe, architectures=[Glm4MoeForCausalLM]. mlx_lm 0.31.3 (the
# exact pinned version here) ships mlx_lm/models/glm4_moe.py, confirmed
# importable via `mlx_lm.utils._get_classes(config)` with ZERO weights loaded
# (Model=mlx_lm.models.glm4_moe.Model, ModelArgs=mlx_lm.models.glm4_moe.ModelArgs).
# That module's Glm4MoeMoE block builds `self.switch_mlp = SwitchGLU(...)`
# (routed experts, gate/up/down all mlx_lm.models.switch_layers.SwitchLinear)
# plus `self.shared_experts = MLP(...)` (dense) for layers >= first_k_dense_replace,
# and plain dense MLP for the early layers -- exactly the mixed dense+MoE shape
# mlx-tune's target-module resolver documents handling.
#
# CONCLUSION: glm4_moe IS supported end-to-end -- via mlx_lm's model_type
# dispatch, not a name in an mlx-tune registry -- and mlx-tune's per-expert
# LoRA targeting will correctly reach mlp.switch_mlp.{gate,up,down}_proj on
# every MoE layer plus mlp.shared_experts.* and the dense early layers.
