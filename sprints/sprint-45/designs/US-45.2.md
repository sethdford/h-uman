# Design for US-45.2: Notarized DMG (P0, L, HIGH)

Worktree: `.worktrees/sprint-45-native-apps`
Branch: `sprint-45-native-apps-ship`
Story: `sprints/sprint-45/stories.md` lines 53–94

## Aspect Panel

| Aspect | Decision |
|---|---|
| **Risk tier** | HIGH — distribution pipeline + App Store Connect credentials in CI + Gatekeeper gate enforcement |
| **Reversibility** | Real-mode is forward-only (released DMG is immutable once notarization ticket issued); dry-run path 100% reversible |
| **Blast radius** | Tag-gated job only fires on `refs/tags/v*`; PR dry-run smoke has zero external side effects |
| **Security surface** | App Store Connect API key (B64 secret), Apple ID, team ID, hardened-runtime enforcement on the shipped `.app` |
| **Determinism** | Dry-run must be hermetic: NO `xcrun` invocations. Real-mode determinism bounded by Apple service latency only |
| **Dependencies** | US-45.1 (`xcodebuild archive` + `codesign` produce the `.app`); US-45.6 (entitlements + `ENABLE_HARDENED_RUNTIME=YES` honored at sign time) |
| **Rollback** | Apple cannot un-staple a notarized ticket; mitigation = un-tag the release, replace GitHub Releases asset, document in runbook |
| **Test seam** | `notarize-dmg-dryrun-smoke` CI step calls `scripts/notarize-mac.sh --dry-run` with `xcrun` stubbed on PATH (exit 99 + invocation log); assert log empty |
| **Observability** | Five distinct exit codes (0/2/3/4/5) map to CI retry policy; `notarytool log <id>` captured on submit failure |
| **Out of scope** | Sparkle auto-update, DMG visual background/layout, Mac App Store distribution (per stories.md line 93) |

## Approach

A single bash script `scripts/notarize-mac.sh` performs the full pipeline against the `.app` produced by US-45.1's `xcodebuild archive` step. The script is invoked from two CI jobs with different gating:

1. **`notarize-dmg-dryrun-smoke`** — added to `.github/workflows/native-apps-fleet.yml` (already PR-triggered on `apps/**`). Runs `scripts/notarize-mac.sh --dry-run` with no secrets. The companion test script stubs `xcrun` on PATH so any accidental real call is detected.

2. **`notarize-dmg`** — added to `.github/workflows/release.yml` (already gated on `tags: ["v*"]`). Runs real-mode with `APP_STORE_CONNECT_API_KEY_B64`, team ID, and key ID from secrets. Job-level `if: startsWith(github.ref, 'refs/tags/v')` is belt-and-braces (the workflow trigger already guarantees this; the job gate makes accidental `workflow_dispatch` invocations fail loud).

The script orders steps as: **preflight (hardened-runtime check) → create DMG → submit (notarytool --wait) → staple (1 retry) → mount → spctl on inner `.app` → detach**. Hardened runtime is verified BEFORE submission so a misconfigured archive fails fast with a clear error instead of an opaque Apple rejection 5 minutes later.

Five distinct exit codes (none of them `1` per AC-45.2.3):

| Code | Meaning | CI / on-call action |
|---|---|---|
| 0 | success | upload artifact (`if: success()`, NOT `if: always()`) |
| 2 | notarytool submit returned status `Invalid` — Apple rejection | DO NOT retry; surface the `notarytool log` URL |
| 3 | notarytool submit network/auth/transient failure | safe to retry once via CI rerun |
| 4 | `stapler staple` failed twice (after 1 in-script retry per AC-45.2.3) | bail; log retained as artifact |
| 5 | `spctl --assess --type execute` on the inner `.app` failed | bail; staple succeeded but Gatekeeper would block — do NOT publish |

The `spctl` check **must** run on the mounted inner `.app` with `--type execute`, NOT `--type open` on the outer DMG (AC-45.2.4 calls this out explicitly; the weaker form passes on a properly-formed DMG even when the inner app is unsigned).

Credential handling: `APP_STORE_CONNECT_API_KEY_B64` is decoded into a `umask 077` tmpfile under `${RUNNER_TEMP}/asc-key-$$.p8`. The entire decode + invocation block is wrapped in `{ set +x; } 2>/dev/null` … `{ set -x; } 2>/dev/null` so shell tracing never echoes the key (AC-45.2.2). The EXIT/INT/TERM trap shreds the key file AND detaches any mounted DMG regardless of exit path.

## Implementation steps (for the implementer agent)

1. **Skeleton `scripts/notarize-mac.sh`** — first non-comment line is `set -euo pipefail` (AC-45.2.2). Header comment block enumerates exit codes 0/2/3/4/5 with one-line meaning each (AC-45.2.3 requires this in a header comment). `usage()`, `--dry-run` flag, `--app <path>` and `--dmg <path>` args. EXIT/INT/TERM trap installed BEFORE any side effect.

2. **Dry-run path lands first** (AC-45.2.1). `--dry-run` prints each intended step to stdout (`echo "[dry-run] would: xcrun notarytool submit …"`) and exits 0 BEFORE any `xcrun` resolution. Land `scripts/test-notarize-dryrun.sh` in the same commit:
   - Create a temp dir; write a stub `xcrun` shell script that `echo "$@" >> "$LOG"; exit 99`.
   - `PATH="$tmpdir:$PATH" scripts/notarize-mac.sh --dry-run --app fake.app --dmg fake.dmg`.
   - Assert: script exits 0; `$LOG` is empty; stdout contains "would: xcrun notarytool submit", "would: xcrun stapler staple", "would: spctl --assess".
   - Run this test in pre-commit AND in the new PR CI job.

3. **EXIT trap implementation** (AC-45.2.2). Trap function: `hu_notarize_cleanup()`:
   - If a DMG was mounted (track mount point in a script-scope var), `hdiutil detach -force "$MOUNT" || true`.
   - If the API key tmpfile exists, `rm -P "$ASC_KEY_FILE"` (macOS equivalent of `shred -u`; `rm -P` overwrites before unlink).
   - If the temp staging dir exists, `rm -rf "$STAGING"`.
   - Trap on `EXIT INT TERM` (NOT just EXIT — Ctrl-C in a manual local run must also clean up).

4. **Hardened-runtime preflight** (AC-45.2.5). In real-mode only (not dry-run), run `codesign -dv --verbose=4 "$APP" 2>&1 | grep -q '\bruntime\b' || { echo "ERROR: hardened runtime not enabled; US-45.6 entitlements + ENABLE_HARDENED_RUNTIME=YES required"; exit 2; }`. The exit-2 mapping here ("would be rejected by Apple") is the correct bucket — same code as a real Apple `Invalid` rejection, since the human action is the same (fix the build, don't retry).

5. **Credential block** (AC-45.2.2). The ONLY lines that touch the key:
   ```bash
   { set +x; } 2>/dev/null
   ASC_KEY_FILE="${RUNNER_TEMP:-/tmp}/asc-key-$$.p8"
   ( umask 077 && printf '%s' "$APP_STORE_CONNECT_API_KEY_B64" | base64 --decode > "$ASC_KEY_FILE" )
   [ -s "$ASC_KEY_FILE" ] || { echo "ERROR: empty key after decode"; exit 3; }
   { set -x; } 2>/dev/null
   ```
   Never `echo` the key, never expand it on a command line. Pass to `notarytool` via `--key "$ASC_KEY_FILE"`.

6. **Submit** (`xcrun notarytool submit "$DMG" --key "$ASC_KEY_FILE" --key-id "$ASC_KEY_ID" --issuer "$ASC_ISSUER_ID" --wait --output-format json --timeout 30m`). Parse `.status` from JSON output:
   - `Accepted` → continue
   - `Invalid` → fetch `notarytool log <id>` to artifact path; exit 2
   - any other status / non-zero exit from `notarytool` → exit 3

7. **Staple** with 1 retry (AC-45.2.3):
   ```bash
   xcrun stapler staple "$DMG" || { sleep 5; xcrun stapler staple "$DMG"; } || exit 4
   ```
   Confirm offline-stapled: `xcrun stapler validate "$DMG"` (used by runbook for post-hoc verification, not as a script gate).

8. **Assess on mounted inner `.app`** (AC-45.2.4). Critical:
   ```bash
   MOUNT="$(hdiutil attach -nobrowse -readonly -plist "$DMG" \
            | plutil -extract 'system-entities.0.mount-point' raw -)"
   APP_INSIDE="$MOUNT/$(basename "$APP")"
   spctl --assess --type execute --verbose=4 "$APP_INSIDE" || exit 5
   hdiutil detach "$MOUNT"
   ```
   The trap detaches on failure paths so we never leak the mount. NEVER use `--type open <DMG>` — AC-45.2.4 explicitly forbids it.

9. **Wire `notarize-dmg-dryrun-smoke` into `native-apps-fleet.yml`** — adjacent to the existing `macos-app-archive` job from US-45.1, no `needs:`, runs on `macos-14`, single step: `bash scripts/test-notarize-dryrun.sh`. No secrets. Lists in `fleet-sota-gate` per sprint convention.

10. **Wire `notarize-dmg` into `release.yml`** — depends on US-45.1's archive artifact (`needs: macos-archive` or reuses the existing release job's `.app`). Job-level `if: startsWith(github.ref, 'refs/tags/v')`. Upload step: `if: success()` (NOT `if: always()` — un-stapled DMG must never publish; this was a critic-flagged failure mode in the original prompt). Captures `notarytool log` artifact on failure with `if: failure()`.

11. **Runbook** at `docs/operations/notarization-runbook.md`: exit code table, secret rotation steps (regenerate App Store Connect API key, update `APP_STORE_CONNECT_API_KEY_B64` repo secret, rotate key ID/issuer if changed), manual recovery (`xcrun notarytool history`, `xcrun notarytool log <id>`, manual staple after late acceptance).

## Risk analysis

| Risk | Probability | Impact | Mitigation |
|---|---|---|---|
| **Secret leak via `set -x` trace** | MED | LARGE | `{ set +x; } 2>/dev/null` bracket; reviewed manually in first dry-run CI log before enabling real-mode |
| **Un-stapled DMG published via `if: always()` on upload** | LOW (prompt called it out) | LARGE | Upload step uses `if: success()`; tested by deliberately failing assess in a local rehearsal |
| **Weak Gatekeeper gate (`--type open` on DMG)** | LOW (AC-45.2.4 pins it) | LARGE | `--type execute` on inner `.app`; inline comment + runbook reiterate |
| **CI auto-retries on Apple rejection (exit 2 lumped with transient)** | MED | MED | Distinct exit codes 2 vs 3; CI rerun policy keys off 3 only; runbook documents the split |
| **Hardened runtime silently OFF** | MED | LARGE | Preflight `codesign -dv` check exits 2 BEFORE submit; depends on US-45.6 landing first |
| **Trap doesn't fire on `kill -9` / OOM** | LOW | SMALL | `${RUNNER_TEMP}` wiped by GitHub Actions at job end; rotation runbook covers worst-case key exposure |
| **Dry-run silently calls xcrun** | LOW | MED | `test-notarize-dryrun.sh` stubs xcrun with exit-99; PR gate enforces |
| **DMG mount left attached on failure** | MED | SMALL | EXIT trap detaches; `-nobrowse` prevents Finder UI; tracked in script-scope var |
| **Notarytool API/JSON shape change between Xcode versions** | LOW | MED | Xcode version pinned via `macos-14` runner image; runbook documents upgrade smoke |
| **API key file world-readable** | LOW | LARGE | `umask 077` in subshell before decode; file under `${RUNNER_TEMP}` which is per-job |
| **Two release jobs race for same notarization ticket** | LOW | SMALL | `release.yml` `concurrency:` group keyed on tag; one tag = one submission |

## Test strategy

- **`scripts/test-notarize-dryrun.sh`** — hermeticity contract test. Negative assertion (zero side effects). Runs in pre-commit + PR CI. This is the only automated test landed in this story.
- **Exit-code matrix** — documented in the runbook as manual injection commands (corrupt the DMG → exit 2; revoke the API key → exit 3; chmod the staple cache to read-only → exit 4; sign the inner `.app` with an ad-hoc identity then re-DMG → exit 5). Implementer is NOT required to automate these (requires paid Apple Dev account + live submissions).
- **First-tag rehearsal** — first release tag is treated as a rehearsal; on-call inspects `notarytool log` artifact + runs `stapler validate` + `spctl --assess --type execute` offline against the downloaded DMG before promoting GitHub Releases asset to "latest".
- **Full test suite** — per `~/.claude/rules/quality-gates.md`, full `./build/human_tests` run before commit even though this story touches no C. Confirms no incidental breakage.

## Acceptance criteria mapping

- **AC-45.2.1** (dry-run prints steps, exits 0, no Apple contact, runs in `notarize-dmg-dryrun-smoke` on every PR) → step 2 + step 9; pinned by `scripts/test-notarize-dryrun.sh` (zero `xcrun` calls under stub)
- **AC-45.2.2** (`set +x`/`set -x` brackets around credentials, `set -euo pipefail` first non-comment line, EXIT trap removes temp DMG staging dir on all exit paths) → step 1 (first line) + step 3 (trap on EXIT/INT/TERM) + step 5 (bracketed block)
- **AC-45.2.3** (staple retries exactly once; second-failure exit code is non-1 and documented in header comment) → step 1 (header comment block lists exit code 4) + step 7 (`|| { sleep 5; xcrun stapler staple … } || exit 4`)
- **AC-45.2.4** (`spctl --assess --type execute` on mounted inner `.app`, NOT `--type open` on DMG, recorded as final step) → step 8 + inline forbidding comment
- **AC-45.2.5** (`codesign -dv` shows `runtime` flag in real-mode; `notarize-dmg` CI job tag-gated, does NOT run on ordinary PRs) → step 4 (preflight) + step 10 (`if: startsWith(github.ref, 'refs/tags/v')`); PR dry-run smoke is the only PR-touching surface
