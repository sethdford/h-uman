# Design for US-45.3: iOS Archive + IPA Export

## Approach

Add `scripts/ios-archive-export.sh` driving `xcodebuild archive` + `xcodebuild
-exportArchive` against the existing `apps/ios/HumaniOS.xcodeproj` (generated
by XcodeGen from `apps/ios/project.yml`). Signing identity flows in via
environment (`APPLE_TEAM_ID`, `IOS_PROVISIONING_UUID`, plus the second
provisioning profile for the widget extension —
`IOS_PROVISIONING_UUID_WIDGET`). Substitute placeholders in
`apps/ios/ExportOptions.plist` with `sed -i.bak`, **install the EXIT/INT/TERM
trap BEFORE sed runs** so a partially-substituted plist with real UUIDs is
never left on disk — and **remove every `2>/dev/null`** in the substitute/
restore block so a restore failure is loud, not silent. Place a hard `plutil`
assertion against the `.xcarchive`'s embedded app `Info.plist` (NOT the
exported IPA-side plist) so the assertion runs even when `SKIP_EXPORT=1`
short-circuits the export step. Pair with
`scripts/check-no-provisioning-leak.sh` that scans for BOTH dashed and
non-dashed (`[0-9a-fA-F]{32}`) UUID forms plus the 10-character uppercase
Team ID pattern, wired into `.githooks/pre-commit` AND the CI job (before and
after archive). `SKIP_EXPORT=1` is only honored when secrets are absent; CI
records "skipped" in its job summary so the fork-PR path is observable, not a
masquerading green.

The existing `.github/workflows/testflight.yml` inlines the ExportOptions.plist
into a heredoc inside the job (line 88) and runs only on tag pushes. This
design **extracts** that contract into a script + plist that runs on every PR
touching `apps/ios/**`. `testflight.yml` is left untouched in this story
(migrating it to call the new script is a follow-up, not a US-45.3
deliverable).

Rationale for the boring shape: a shell script + `xcodebuild` is the canonical
Apple-blessed path; reaching for fastlane / custom Ruby is unjustified for a
single archive+export contract.

## Implementation steps (for the implementer agent)

1. **Create `apps/ios/ExportOptions.plist`** with three literal placeholders
   (`__TEAM_ID__`, `__PROVISIONING_PROFILE_UUID__`,
   `__PROVISIONING_PROFILE_UUID_WIDGET__`) and a `provisioningProfiles` dict
   keyed by both bundle IDs (`ai.human.ios`, `ai.human.ios.widget` — both
   from `apps/ios/project.yml`). Verify `plutil -lint` accepts it.
2. **Create `scripts/check-no-provisioning-leak.sh`** with two-pattern UUID
   detection (`[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}`
   AND `\b[0-9a-fA-F]{32}\b`) + Team ID detection (`\b[A-Z0-9]{10}\b`).
   Unit-test on fixture strings (positive: dashed UUID, 32-hex UUID, Team
   ID; negative: 31-hex string, lowercase 10-char string, placeholder
   `__TEAM_ID__` text). No `2>/dev/null`.
3. **Create `scripts/ios-archive-export.sh`** in this order:
   a. Header + `set -euo pipefail` + required-env validation (require
      `APPLE_TEAM_ID` + both provisioning UUIDs unless `SKIP_EXPORT=1`)
   b. Define `cleanup()` function + `trap cleanup EXIT INT TERM` —
      **installed BEFORE the first sed call** (ordering enforced by smoke
      test on script source line numbers)
   c. Three `sed -i.bak` substitutes — every exit status checked, NO
      `2>/dev/null`
   d. `xcodebuild archive` invocation (respects `SKIP_EXPORT` for signing-off
      mode: `CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO
      CODE_SIGN_IDENTITY=""`)
   e. `plutil -extract CFBundleIdentifier raw
      "<archive>/Products/Applications/HumaniOS.app/Info.plist"` +
      `CFBundleShortVersionString` — fires **before** the `SKIP_EXPORT` gate
   f. `if [[ "${SKIP_EXPORT:-0}" != "1" ]]; then xcodebuild -exportArchive …;
      fi`
   g. Post-export: run `check-no-provisioning-leak.sh` against the IPA
      contents (only if export ran)
4. **Wire `.githooks/pre-commit`** to invoke leak check on staged files
   matching `apps/ios/*.plist`, `apps/ios/*.xcconfig`, `apps/ios/*.entitlements`,
   and the corresponding `apps/macos/` paths.
5. **Add CI job `ios-archive`** to `native-apps-fleet.yml`:
   - `runs-on: macos-latest`, `timeout-minutes: 20`
   - Path filter inherited from workflow-level (`apps/**`)
   - Secret-presence detection at the top of the job:
     `if [[ -z "${APPLE_TEAM_ID:-}" ]]; then echo "SKIP_EXPORT=1" >>
     $GITHUB_ENV; echo "::notice::iOS archive: SKIP_EXPORT=1 (secrets absent
     — fork PR)"; fi`
   - Run leak check before archive, archive, run leak check after IPA export
   - Emit `skipped: true|false` line to `$GITHUB_STEP_SUMMARY`
6. **Register `ios-archive` as a required check in `fleet-sota-gate`**:
   - Append `- ios-archive` to `jobs.fleet-sota-gate.needs`
   - Add `IOSA: ${{ needs.ios-archive.result }}` to the env block
   - Add `| iOS archive + IPA | \`$IOSA\` |` to the summary table
   - Add `|| [ "$IOSA" != success ]` to the all-green guard
7. `/verify` runs `tests/ios/test_ios_archive_export.sh` + a `plutil -lint`
   on the substituted plist fixture.

## Risks

- **Trap-restore race (MED / LARGE):** if the script is killed between sed
  and trap-install, the unsubstituted file with real UUIDs persists.
  *Mitigation:* install trap BEFORE sed (enforced by smoke test that greps
  line numbers); `.gitignore` covers `.bak` so even a dirty worktree won't
  leak via commit; pre-commit hook is the final defense. Three-layer
  defense.
- **Silent failure of substitution (MED / LARGE):** prior critic flagged
  `2>/dev/null` masking real errors. *Mitigation:* explicit rule — no
  `2>/dev/null` in this file's substitute/restore block, enforced by a
  `grep -n '2>/dev/null' scripts/ios-archive-export.sh` smoke-test
  assertion (must be 0 hits in those line ranges).
- **AC-45.3.3 dead-code-path (HIGH / LARGE):** if plutil assertions only
  fire after export, `SKIP_EXPORT=1` skips them entirely and the AC is
  unverifiable on fork PRs. *Mitigation:* plutil assertions target the
  `.xcarchive`'s embedded app Info.plist (exists after archive regardless
  of export) and run BEFORE the `SKIP_EXPORT` gate. Pinned by a smoke test
  that asserts the plutil block's line number precedes the `SKIP_EXPORT`
  branch's line number in the script source.
- **Leak-regex false negatives (MED / LARGE):** prior critic noted the
  non-dashed 32-hex form is invisible to dashed-only regexes.
  *Mitigation:* explicit two-pattern grep; pinned by a fixture test that
  includes BOTH forms; Team ID matched by whole-line + word-boundary.
- **Leak-regex false positives (LOW / SMALL):** binary blobs may contain
  incidental 32-hex strings. *Mitigation:* leak check scoped to
  text-bearing file extensions; documented in script header.
- **Widget extension provisioning skipped (MED / LARGE):** `project.yml`
  declares two bundle IDs (`ai.human.ios` + `ai.human.ios.widget`); a
  single-UUID export plist would fail signing for the embedded extension.
  *Mitigation:* ExportOptions.plist contains BOTH bundle ID entries with
  separate placeholders; script requires both env vars.
- **CI runtime > 20 min (LOW / MED):** Xcode cold-build on GH macOS runners
  can be slow. *Mitigation:* `actions/cache` on `~/Library/Developer/Xcode/DerivedData`
  keyed on Swift hash; if cache miss exceeds budget, escalate via follow-up.
- **Bundle ID mismatch with US-45.6 (MED / MED):** if US-45.6 changes the
  bundle ID, the `provisioningProfiles` dict drifts. *Mitigation:* both
  stories pin `ai.human.ios` + `ai.human.ios.widget` per `project.yml`;
  bundle IDs are simple string literals, easy to grep + update.
- **Observability gap on skipped runs (LOW / MED):** a `SKIP_EXPORT=1` job
  shouldn't masquerade as full coverage. *Mitigation:* `::notice::` +
  `skipped: true|false` in `$GITHUB_STEP_SUMMARY`; artifact name suffix
  `-skip` when skipped.

## Test strategy

- **`tests/ios/test_ios_archive_export.sh`** — Linux-portable (no Xcode):
  - `test_substitutes_team_and_both_uuid_placeholders` (3 substitutions)
  - `test_trap_restores_on_exit`
  - `test_trap_restores_on_int` (subshell + `kill -INT`)
  - `test_trap_restores_on_term`
  - `test_aborts_when_required_env_unset`
  - `test_aborts_when_widget_uuid_unset_without_skip`
  - `test_no_silent_redirect_in_substitute_restore_block`
  - `test_plutil_block_precedes_skip_export_gate`
  - `test_trap_install_precedes_first_sed`
  - `test_leak_detects_dashed_uuid`
  - `test_leak_detects_non_dashed_uuid`
  - `test_leak_detects_team_id`
  - `test_leak_ignores_placeholder_text`
  - `test_leak_ignores_31_hex_string`
- **CI smoke** — `ios-archive` job archives + asserts on every PR touching
  `apps/ios/**` or `apps/shared/**`. Real signing only when secrets present.
  `fleet-sota-gate` enforces it as required.
- **No real-xcodebuild mock** — exercised by CI; mocking adds complexity
  without catching real failure modes.

## Aspect-Panel notes (pre-merge — MANDATORY per story directive)

- `trap cleanup EXIT INT TERM` line number < first `sed -i.bak` line number
- Zero `2>/dev/null` in the script
- `plutil` block line number < `SKIP_EXPORT` branch line number
- plutil target path is the `.xcarchive`'s embedded app Info.plist, not the
  exported IPA path
- Leak regex covers BOTH dashed UUID and non-dashed `[0-9a-fA-F]{32}` forms
- `.gitignore` covers both `.bak` and `.tmp` suffixes
- ExportOptions.plist contains BOTH `ai.human.ios` and `ai.human.ios.widget`
  provisioning entries
- CI job records `skipped: true|false` in `$GITHUB_STEP_SUMMARY`
